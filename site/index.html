Install

Five steps. About two minutes.

Steps 3 to 5 are needed once, because these builds are not signed or notarized with an Apple certificate yet.

Download the .dmg

Grab Droidwire-1.4.1-arm64.dmg from the download button (a beta prerelease; the unsigned app needs the quarantine step below). By installing, you accept the terms of use. Short version: it is free, provided as-is, and you should keep backups of anything irreplaceable.

Drag Droidwire into Applications

Open the downloaded .dmg and drag the Droidwire icon onto the Applications folder. You can then eject the .dmg.

Open the app once. macOS will block it. Click Cancel.

Open Droidwire from Applications. macOS shows an alert, usually "Droidwire is damaged and can't be opened". The app is not damaged; macOS says this about any app that isn't signed with an Apple certificate. Click Cancel (do not click "Move to Trash") and go to the next step.

Run one command in Terminal

Open Terminal (press Cmd + Space, type "Terminal", press Enter). Paste this command and press Enter:

xattr -dr com.apple.quarantine /Applications/Droidwire.app

What it does: macOS tags every downloaded file with a "quarantine" flag, and that flag is what triggers the "damaged" alert on unsigned apps. This command removes the flag from the Droidwire app only. It changes nothing else on your Mac and prints nothing when it succeeds.

Reopen Droidwire

Open Droidwire again from Applications (or Launchpad or Spotlight). It now opens normally and stays that way. You never repeat steps 3 to 5.

Plug in your phone (or use Wi-Fi) and the built-in setup walks you through connecting it. There is nothing to sign up for.

Found a bug? Grab the log via Droidwire menu > Show Logs in Finder and open an issue on GitHub with the log attached. Every report makes the app better.
FAQ

Questions, answered.

Is Droidwire really free?

Yes. It is free to download and use, with no paid tier, no ads and no account. The source code is released under the MIT License.

Do I need to sign up or give any data?

No. There is no account, no sign-up and no email prompt. The app collects no personal data, no analytics and no crash reports. The only request it makes on its own is an optional check of GitHub for a newer version, which you can switch off.

Do I need to install anything on my phone?

No. Droidwire uses Android's own built-in protocols: USB debugging or Wireless debugging. Nothing is installed on the phone, ever.

Why does macOS say the app is damaged?

Builds are not signed and notarized with an Apple Developer certificate yet, and macOS reacts that way to any unsigned downloaded app. The install guide shows the one-time fix. Prefer not to run an unsigned app? Build it from source and read the code first.

How do I know it is safe?

The code is public and MIT licensed, so you can read it or build it yourself. Files only move between your devices, and nothing is sent to a server. Note that USB debugging gives your Mac access to the phone, so turn it off when you do not need it.

Which Macs and phones work?

Apple Silicon Macs on macOS 12 Monterey or later. Intel Macs are not supported. Android 8.0 or later for USB mode, Android 11 or later for Wi-Fi mode. Hardware testing is limited to one phone and one Mac (see the compatibility table below), so reports of what works are welcome.

What is the difference between USB and Wi-Fi? Where is MTP?

USB and Wi-Fi both use ADB and unlock every feature, including device tools and APK handling. USB needs a cable; Wi-Fi needs Android 11 or later and a one-time pairing. MTP, a simpler mode that needs no USB debugging, is deferred: it is not part of this beta and is not in the app.

Is there a Windows, Linux or iOS version?

No, and none is planned. Droidwire is a Mac app for Android phones.

How do I report a bug or contribute?

Open an issue on GitHub, or read the contributing guide to send a fix.
